# Lasyapriya & Naresh — Wedding Invitation

Premium bilingual React/Vite wedding invitation based on the supplied Arena design.

## Included
- Original Arena visual system and sections
- English / Telugu language toggle
- Ten curated photo frames, including separate bride and groom portraits
- Animated invitation gate, scroll reveals, petals and ornamental motion
- Countdown to 18 November 2026, 10:12 AM IST
- Synthesised royalty-free instrumental-style background music with play/pause control
- Google Maps directions and map embeds
- WhatsApp sharing

## Deploy
1. Upload this project folder to a GitHub repository.
2. In Vercel, choose **Add New → Project**, import the repository.
3. Keep the defaults: Build Command `npm run build`, Output Directory `dist`.
4. Deploy. Vercel will provide a public HTTPS URL.

This is a Vite source project, not a directly openable `index.html` file. It must be built/deployed first.
The music starts only after the visitor taps Open Invitation, as required by mobile browser audio policies.

## Before public sharing
Confirm Haldi and Reception venue/time details. They are intentionally marked “to be announced” because no confirmed details were provided.
Please verify the family-name spellings from the printed invitation before sharing publicly.
